# IdőképHét – Időjárás elemző weboldala

Iskolai II. projekt (10.C 2F, 2026.11.03.). A klub mérőállomást épít, az oldal magyarországi időképet mutat (jelenleg példaadatokkal).

## Fájlok
- `index.html` – az oldal váza és tartalma
- `style.css` – a teljes stílus
- `Terv.txt` – követelmények, vázlatok, feladatmegosztás
- `fontawesome/` – ide kell másolni a Font Awesome Free `css` és `webfonts` mappáját (az `all.min.css` miatt az ikonokhoz)

## Futtatás
Nyisd meg az `index.html` fájlt egy böngészőben. Telepítés nem kell.

## Feladatmegosztás
- Név1: HTML-váz, menü, programkártyák
- Név2: CSS, mobil elrendezés, időkép-kártyák
- A másik fél mindig ellenőrzi, mielőtt a feladat késznek számít.

## Git
Egy kipróbált módosítás után: `git add .` majd `git commit -m "rövid leírás"`.
